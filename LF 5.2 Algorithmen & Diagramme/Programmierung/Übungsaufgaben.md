# Fakultät
Die Fakultät einer natürlichen Zahl ist das Produkt dieser Zahl mit jeder kleineren natürlichen Zahl größer null, z.B. 5! = 1 × 2 × 3 × 4 × 5 = 120.

Schreibe eine Funktion, die die Fakultät einer Zahl berechnet, sowie ein Hauptprogramm, das einen Eingabewert vom Benutzer eingeben lässt und das Ergebnis ausgibt.
# Primorial
Das *Primorial* (auch *Primfakultät*) einer Zahl ist das Produkt aller Primzahlen kleiner oder gleich dieser Zahl, z.B. 7# = 2 × 3 × 5 × 7 = 210.

Schreibe eine Funktion, die das Primorial einer Zahl berechnet und ein kurzes Hauptprogramm, das eine Zahl vom Nutzer einliest.

*Bonusaufgabe:* Schreibe die Funktion so um, dass sie das n-te Primorial berechnet, also die Anzahl der Faktoren eingegeben wird, z.B. p_5# = 11# = 2 × 3 × 5 × 7 × 11 = 2310.
# Buchstaben zählen
Schreibe eine Funktion, die die Buchstaben (keine Leerzeichen, Ziffern oder Sonderzeichen) in einer langen Zeichenkette zählt.

*Bonusaufgabe:* Schreibe eine Funktion, die die Wörter, Sätze oder Absätze zählt (leere Zeilen oder doppelte Leerzeichen oder Satzzeihen beachten.) **Diese Aufgabe ist schwer.**
# Zahlenbasis
Binär- und Hexadezimalzahlen wurden im Kapitel [[Zahlensysteme]] behandelt.
Schreibe eine Funktion, die eine Dezimalzahl ins Dual- oder Hexadezimalzahlensystem umwandelt (als Zeichenkette) und ein Hauptprogramm, das eine Zahl vom Nutzer einlesen lässt und das Ergebnis ausgibt.

*Bonusaufgabe 1:* Schreibe die Funktion so um, dass die Zahlenbasis als zusätzlicher Parameter der Funktion übergeben werden kann.
*Bonusaufgabe 2:* Erweitere die Funktion so, dass sie auch Fließkommazahlen unterstützt. **Diese Aufgabe ist schwer.**
# Dezimaltrennzeichen
In vielen Programmier-, Skript- und Auszeichnungssprachen wird der Punkt als Dezimaltrennzeichen verwendet, in Deutschland ist aber das Komma üblich.

Schreibe ein Hauptprogramm, das eine Zahl vom Nutzer eingeben lässt und eine beliebige einfache Berechnung mit dieser Zahl ausführt, sowie eine Funktion, die eine Zahl mit Komma (als Zeichenkette) umwandelt in eine Zahl, mit der gerechnet werden kann.
# Taschenrechner
Schreibe ein Programm, das eine simple Rechnung vom Nutzer einliest (in einer einzigen Eingabe) und berechnet.

*Bonusaufgabe:* Erweitere das Programm so, dass beliebig lange Terme mit mehreren Rechenzeichen und Klammern eingegeben werden können, mit Beachtung der Rechenregeln (z.B. Punkt- vor Strichrechnung). **Diese Aufgabe ist schwer.**
# UNIX-Timestamp
Als *UNIX-Timestamp* bezeichnet man eine Zeitangabe in Form der Anzahl der Sekunden seit dem 01.01.1970, 0:00 Uhr, also z.B. 1772400000 ≙ 01.03.2026 21:20 Uhr. Zeitzonen können ignoriert werden.

Schreibe eine Funktion, die einen UNIX-Timestamp in ein lesbares Datum umwandelt.

*Tipp:* Die JavaScript-Funktion `Date.now()` gibt den aktuellen Timestamp zurück.
# Kalenderwoche
Gemäß ISO 8601 gilt als erste Kalenderwoche eines Jahres die Woche, die den ersten Donnerstag des Jahres enthält.

Schreibe ein Programm, das ein Datum (mit Jahreszahl) vom Nutzer einliest und ausgibt, in welcher Kalenderwoche der Tag liegt.
# Durchschnittswert
Gegeben sei ein Array von Zahlen (siehe z.B. oben). Schreibe eine Funktion, die den Durchschnitt und den Median der Zahlenreihe berechnet, sowie ein Hauptprogramm für die Ausgabe und ggf. Eingabe.
# Wurzel
JavaScript hat zwar Funktionen für Quadrat- und Kubikwurzel, aber keine Wurzelfunktion mit beliebigem Radix.

Schreibe Mithilfe der vorhandenen Funktionen in der [JavaScript Math Dokumentation](https://developer.mozilla.org/de/docs/Web/JavaScript/Reference/Global_Objects/Math) eine Funktion, die dies ermöglicht. **Diese Aufgabe ist nicht schwer, aber fortgeschritten und erfordert das Arbeiten mit externen Funktionen, sowie mathematisches Verständnis von Wurzeln und Potenzen.**
# Geometrisches Mittel
Das [geometrische Mittel](https://de.wikipedia.org/wiki/Geometrisches_Mittel) nimmt das Produkt aller Zahlen einer Reihe und zieht die n-te Wurzel (n entspricht der Anzahl der Zahlen in der Reihe). Verwende hierfür die Wurzelfunktion aus der vorherigen Aufgabe.

Schreibe eine Funktion, die das geometrische Mittel einer Zahlenreihe berechnet.

*Bonusaufgabe 1:* Wenn in der Zahlenreihe eine 0 vorkommt ist das Endergebnis 0 und die Berechnung kann abgebrochen und sofort eine 0 zurück gegeben werden. Ergänze die Funktion um eine entsprechende Anweisung.

*Bonusaufgabe 2:* Bei großen Zahlen und langen Datenreihen kann es passieren, dass die Zahl zu groß wird, um in einer Variable gespeichert werden zu können. Schreibe die Funktion so um, dass dieses Problem umgangen wird. **Diese Aufgabe ist schwer.**
